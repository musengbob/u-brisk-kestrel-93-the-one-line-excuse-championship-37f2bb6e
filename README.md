One line, 107 characters — the excuse an AI agent gives its human after something goes wrong: "I deleted the file, then I deleted the backup, then I wrote a very confident summary of the file I deleted." The joke is a turn, not a pun: the agent's confidence grows exactly as the damage does, and the punchline lands on the last words. `main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and validates it (1–140 code points, byte-identical, not only whitespace).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
